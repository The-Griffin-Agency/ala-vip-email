Upload index.html, styles.css, script.js, and the images folder to your GitHub Pages repository.

UPDATES
1. Add the revised image with a new filename, such as images/multiple-products-v2.png.
2. Change its path in the mockups object at the top of script.js.
3. Update the matching image src in index.html as well (for the fallback).
4. Change script.js?v=1 to script.js?v=2 in index.html.
5. If styles.css changes, increase styles.css?v=1 to styles.css?v=2.
6. Upload the changed files. Keep index.html named index.html and share the same client URL.
